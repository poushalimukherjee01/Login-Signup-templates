# Poushali_Login_Template

## Description
A modern, responsive login template with interactive features:
- Password show/hide toggle
- Password strength indicator
- Input validation
- Animated login button on submit
- Dark mode toggle

## Dependencies
- None (Vanilla HTML, CSS, and JavaScript)
-  Include `Poppins` font from Google Fonts

## Files
- `index.html` – Main template file
- `style.css` – Styles for layout and UI
- `script.js` – JavaScript for interactivity
- `assets/` – Images and logos used in the template

## Integration
1. Copy the folder into the main project directory.
2. Link the CSS and JS files in your HTML if needed.
3. Open `index.html` in your browser to view the template.
